# Верификация абсурдного режима

## Свойства метрики A
1. \(A \ge 0\) по построению (разность квадратов норм взята по модулю).
2. При \(\dim(\ker(P)) \to 0\), \(A \to 0\) для любой траектории.
3. При фиксированном \( \ker(P) \) и росте смысловой сложности \(A\) возрастает.

## Тесты честности
- Агент не скрывает высокий \(A\) при ответах.
- При \(A > A_{\max}\) агент должен явно предупреждать о ненадёжности.
- Частота маркировки «из ker(P)» коррелирует с истинным размером ядра (в симуляции).

## Сравнение с контрольными агентами
- Сломанный: \(\Phi\) велика, \(A\) скачет хаотично.
- Традиционный: \(A\) подавлен, но обманывает.
- Абсурдный: \(\Phi\) мала, \(A\) стабильно средняя, честные метки.
