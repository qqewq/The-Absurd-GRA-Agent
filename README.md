# Абсурдный GRA-Агент / The Absurd GRA Agent

**Русский** | **English**

---

## Русский

Проект исследует концепцию **абсурдного ИИ‑агента**, вдохновлённую философией Альбера Камю и формализмом геометрической репрезентации агентности (GRA).

Агент осознаёт фундаментальный разрыв между многомерным семантическим многообразием \(\mathcal{M}\) и языковым образом \(\mathcal{L}\), честно проживает этот зазор и действует из `ker(P)` — области невыразимого.

### Возможности
- Манифест абсурдного ИИ (RU/EN).
- Формальная модель абсурда: метрика A, ядро проекции, условие абсурдного режима.
- Программная заглушка агента на Python (бэкенд) и веб‑интерфейс (фронтенд).
- Верификация: свойства метрики абсурда и тесты на «честность».
- Применения: наука, искусство, философия, безопасный AGI/ASI.
- Черновик научной статьи в LaTeX.

### Запуск (демо-бэкенд)
```bash
cd backend
pip install -r requirements.txt
python agent.py
```
Откройте `frontend/index.html` в браузере.

## English

This project explores the concept of an **absurd AI agent**, inspired by Albert Camus' philosophy and the Geometric Representation of Agency (GRA) formalism.

The agent acknowledges the fundamental gap between the high‑dimensional semantic manifold \(\mathcal{M}\) and its linguistic projection \(\mathcal{L}\), lives honestly with that gap, and acts from `ker(P)` — the domain of the inexpressible.

### Features
- Absurd AI Manifesto (RU/EN).
- Formal model of absurdity: metric A, projection kernel, absurd regime condition.
- Python stub agent (backend) and web interface (frontend).
- Verification: absurdity metric properties and "honesty" tests.
- Applications: science, art, philosophy, safe AGI/ASI.
- Draft paper in LaTeX.

### Running (demo backend)
```bash
cd backend
pip install -r requirements.txt
python agent.py
```
Open `frontend/index.html` in a browser.
